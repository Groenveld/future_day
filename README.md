# Future Day (Zukunftstag)

Projects for a Zukunftstag: a day of building things with code, the cloud, a Raspberry Pi and Arduinos.

| Folder | Project | Time |
|---|---|---|
| [project1](project1/) | His own website: Terraform puts a page in S3 | ~30 min, warm-up |
| [project2](project2/) | His own Minecraft server on EC2 | ~45 min, the fun part |
| [project3](project3/) | "What does the AI see?" camera: Pi → S3 → Lambda → Rekognition | 1–2 h, main build |
| [project4](project4/) | Room guardian: a sensor triggers a photo, emailed through SNS | 2+ h, stretch goal |
| [project5](project5/) | Photo counter: a 4-digit display on an Arduino | bonus |
| [project6](project6/) | Cloud knob: a rotary encoder synced with AWS IoT Core | bonus |

Hardware: Raspberry Pi 5 with a Logitech C920 webcam, Arduino Nano 33 BLE Sense, Arduino Uno, RobotDyn TM1637 display, KY-040 rotary encoder.
